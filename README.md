## Installation

```bash
# http
git clone https://github.com/Lmpkessels/TLPI.git
cd TLPI
```

```bash
# ssh
git clone git@github.com:Lmpkessels/TLPI.git
cd TLPI
```

## Usage

```bash
# If target directory is included else only file
gcc directory/file.c -o target_directory/file
```

```bash
# Compilation with header file
gcc directory_of_header_file/ directory_of_header_file/file.c directory/main_file.c
-o target_directory/file
```
